# 个人技术知识库

> 本文件由 `build_kb.py` 生成；结构说明是固定的，内容请写到 `项目/`。

## 五个顶级目录

| 目录 | 作用 | 能改吗 |
|---|---|---|
| `项目/` | 按项目归档的唯一真身 | **只能改这里** |
| `时间线/` | 年/月/日视图；创建日和每个修改日各一份副本 | 自动生成，勿手改 |
| `类型/` | 按 8 个类型浏览（再按项目分） | 自动生成，勿手改 |
| `主题/` | 按 8 个技术主题浏览（再按项目分） | 自动生成，勿手改 |
| `索引/` | 总览、标签、类型/主题/状态、月度视图 | 自动生成，勿手改 |

## 唯一规则

1. 只编辑 `项目/<项目>/YYYY-MM-DD_核心问题.md`。
2. 时间线、类型、主题、索引都是副本；改了会被下一次重建覆盖。
3. 追加修改只改真身：更新 frontmatter 的 `updated`，在「变更记录」末尾加一行
   `- YYYY-MM-DD HH:MM 补充：...`，然后重新构建。
4. 文件名永不改；同一天同一核心问题才追加，不同问题新建。

## 常用命令

```bash
# 重建全部视图
python build_kb.py

# 只校验，不写盘
python build_kb.py --check

# 校验所有副本与真身的哈希
python build_kb.py --verify-hashes

# 检索
python search.py --query "日期:2026-10-25"
python search.py --query "主题:导航"
```

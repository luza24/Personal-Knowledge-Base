# Gazebo 机器人导航场地 world 文件编写

> 整理日期：2026年9月17日 13:06

## 环境信息
- 操作系统：Windows 11 Home China 10.0.26200（Shell: Git Bash）
- 仿真软件：Gazebo Classic（SDFormat 1.6，物理引擎 ODE）
- 场景目标：搭建机器人导航仿真场地（含起点/终点、楼宇、停车区、人偶、红绿灯等）

## 涉及文件
- `C:\Users\luza\robot_nav_field.world`（新建）
  - 完全自包含的 world 文件，所有模型均用内联几何体（box/cylinder/sphere）搭建，
    不依赖 `model://sun`、`model://ground_plane` 等外部模型库，离线可直接加载。

## 修改方案
- **坐标系约定**（与需求一致）：
  - 原点 (0,0,0) = 图纸上方「起点/终点」斑马线区域几何中心
  - +X 向下、+Y 向右、+Z 向上，地面 z=0
- **场地总尺寸**：约 7.5m(X) × 5.0m(Y)，核心道路宽 0.6m
- **world 结构（14 个 model）**：
  | model | 内容 | 关键位姿 |
  |---|---|---|
  | `ground_plane` | 地面 | 7.5×5×0.05，上表面 z=0 |
  | `boundary_walls` | 四边围墙 | 高 0.5m |
  | `roads` | 环形主干道 | 右 Y≈1.2 / 左 Y≈-1.2，宽 0.6m |
  | `zebra_crossing` | 起点斑马线 | 中心 (0,0,0) |
  | `traffic_light_top` | 顶部红绿灯 | 起点线 -X 方向，立杆+红黄绿 |
  | `traffic_light_bottom` | 底部红绿灯 | (6.0, 0) |
  | `building_a/b/c` | 楼宇A/B/C | (1.5/2.8/4.1, 0.5) |
  | `parking_slots` | P区 3 车位 | (1.5/3.5/5.5, 2.5) |
  | `car_1/2/3` | 蓝色电动车 | 对应 3 个车位 |
  | `p_sign_1/2/3` | 蓝色 P 指示牌 | 各车位右侧 Y=2.75 |
  | `crowd_a/b` | A/B 街区人偶 | (1.5/-0.8)、(3.0/-0.8) |
  | `station_building_d` | 站房&楼宇D | 左下角 (5.0, -1.0) |
- **关键技术处理**：
  - 薄板用视觉层叠（底板 z 稍高 + 上层贴片），避免 z-fighting（如斑马线底板 0.006、条纹 0.013）。
  - 车轮用 cylinder + 绕 Y 轴旋转 90°（roll=1.5708）实现水平轴。
  - 红绿灯三灯竖直排列：上红、中黄、下绿。
  - 机器人出生点用注释的 `<include model://turtlebot3_burger>` 示例占位。

## 待确认的关键假设
1. **60cm 间距落点**：需求「楼宇右缘→停车区左缘 60cm」与「停车位 Y=2.5」无法同时精确成立。
   按「楼宇右缘 Y=0.9 → 60cm 主干道 Y=0.9~1.5 → 停车区 Y≈2.2」处理（60cm 作为导航道路宽度）。
2. **楼宇尺寸**：取 0.8m×0.8m 底 + 0.5m 高（需求推断约 1.6m 宽偏大，已缩小以保证间距）。
3. **红绿灯位姿**：需求写的 `(0,0,0.6)` 中 0.6 按「立杆高 0.6m、位于起点线 -X 方向约 0.6m」实现。

## 结果与结论

- 尚未在 Gazebo 中实机加载验证（用户需自行 `gazebo robot_nav_field.world` 检查 SDF 解析与功能区位姿）。

### 第二轮：按百分比坐标重建
- 地图由 7.5m×5m 改为 **7m×7m 正方形**，按「图像左上角原点、向右/向下为正」的百分比坐标重排所有区域。
- 换算公式：世界 X(向下) = 图像Y% × 7 − 0.525；世界 Y(向右) = 图像X% × 7 − 6.3。
- A街区明确为 Y 轴方向宽度 0.6m 的条带。
- 楼宇D/站房 → 垂直排列的 4 个垃圾桶。

### 第三轮：L 形道路 + 结构改造

- 楼宇 A/B/C 长宽减半（0.7→0.35），A 位置不变，间距减半（0.88→0.44）。

### 第四轮：斑马线 + L 路位置修正

- 斑马线改黑白等宽条纹（每条 0.1m，共 6 条），宽 0.6m。
- 顶部斑马线（中央上侧 (0,-3.3)）：行人南→北，条纹东西向长边。

### 第五轮：道路端点对齐

- `road_vertical`（L纵）：X 跨度 0.6~5.5 → **2.1~5.5**（长 4.9→3.4，北端止于横向路拐角）。

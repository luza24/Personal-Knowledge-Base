# Chrome 安装 Bypass Paywalls Clean 付费墙绕过扩展

> 整理日期：2026年10月8日 20:59

## 环境信息
- 操作系统：Windows 11 Home China（10.0.26200），Git Bash 环境
- 浏览器：Chrome（强制要求 Manifest V3 扩展，MV2 被拒绝加载）
- 目标扩展：Bypass Paywalls Clean（付费墙绕过浏览器扩展）
- 用户最初提供的仓库：`csns1/bypass-paywalls-chrome-clean-magnolia1234`（第三方 fork，2022 年，MV2 旧版）

## 报错记录
- 报错信息（Chrome `chrome://extensions` 加载已解压扩展时）：
  ```
  Failed to load extension
  File ~\bypass-paywalls
  Cannot install extension because it uses an unsupported manifest version.
  Could not load manifest.
  ```
- 现象：扩展无法加载。
- 触发条件：用户给的 `csns1` fork 是 Manifest V2 版本（`manifest_version: 2`，v2.7.1.1），而当前 Chrome 已强制要求 MV3。

## 涉及文件
- 旧版（已删除）：`C:\Users\luza\bypass-paywalls`（MV2，v2.7.1.1，来自 csns1 fork）
- 新版（最终保留，可加载）：`C:\Users\luza\bypass-paywalls-mv3`（MV3，v4.4.0.2，来自 taher-lokhand21 fork）
- 临时文件（已清理）：`bpc-mv3.tar.gz`、`_probe`

## 修改方案
1. 首次 `git clone` csns1 仓库成功，但该仓库是 MV2 旧版，Chrome 拒绝加载。
2. 官方 `magnolia1234/bypass-paywalls-chrome-clean` 已从 GitHub 下架（版权 DMCA），搬去 GitLab；GitLab 对脚本下载有 Cloudflare 人机验证拦截（curl 拿到的是 "Just a moment..." 5KB HTML），无法直接下载。
3. `raw.githubusercontent.com` 被墙（HTTP 000），但 `github.com` 的 git clone 可用。
4. 用 GitHub 搜索 API（`api.github.com/search/repositories`）找到多个 fork，逐个 `git clone` 探测 `manifest.json` 的 `manifest_version`，命中 MV3 版本（taher-lokhand21 的 fork，v4.4.0.2）。
5. 删除旧 MV2 目录与临时文件，将 MV3 版重命名为 `bypass-paywalls-mv3`，作为最终加载目录。

## 结果与结论
- 已解决：拿到可被当前 Chrome 加载的 MV3 版本（v4.4.0.2），目录 `C:\Users\luza\bypass-paywalls-mv3`。
- 最终加载步骤：Chrome 打开 `chrome://extensions` → 开启「开发者模式」→「加载已解压的扩展程序」→ 选择 `C:\Users\luza\bypass-paywalls-mv3` 目录。
- 注意事项：该版本仍是第三方 fork，非原作者官方发布，建议仅在信任的浏览器环境使用，勿在登录敏感账号时长期挂载。

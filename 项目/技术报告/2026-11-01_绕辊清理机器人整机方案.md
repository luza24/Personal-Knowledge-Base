# 绕辊清理机器人整机方案（选型、计算单元、通信与控制）

> 整理日期：2026年11月01日 19:39
> 项目：技术报告 ｜ 状态：进行中 ｜ 标签：`方案选型` `ros` `yolo` `docx` `视觉`

## 背景 / 目标

纺织车间细长滚筒两端容易缠绕毛线，人工清理存在夹伤/割伤风险，且停机时间不可控。目标是用“轮式移动底盘 + 7 轴机械臂 + 末端钩包刀/振动刀 + 视觉检测”实现巡逻、停靠、检测、切割。

当前口径：

- 本期做 **检测 + 切割**；
- 切后线头清除、机床联锁/挂牌上锁、切后复检后置；
- 末端 **不装补光灯**，依赖车间环境光；
- 末端质量 ≤3.5 kg；
- 当前仍是概念设计，未完成整机、切割、检测闭环或安全验证。

本次对话的交付目标：形成可评审的整机方案、计算单元选型、SolidWorks 风格示意图/爆炸图、YOLO 工业成熟度评估、一体化与通信/控制架构。

## 关键问题与约束（不是报错）

| 问题 | 结论/状态 |
|---|---|
| 无补光下侧成像 | **最高风险**；如果图像里毛线不可分割，任何模型都无效；必须现场拍图验证 |
| H6Mini 防尘 | 官方写“无粉尘”，纺织飞絮环境需书面确认；备选 MPO-700 |
| H6Mini 25A 与 Diana 峰值 | 25A×48V=1200W；Diana 峰值估 20–31A，1.5kW 时 31.3A，**可能超过 25A**；原文档“峰值均有余量”已纠正 |
| Diana 控制箱制式 | 标准支持 AC110–240V / DC45–65V；必须确认 DC 版本，AC-only 版本需逆变器，方案不成立 |
| 低电量电压 | H6Mini LFP 低电量可能低于 Diana 的 45V 下限；需 BMS 限放电或 48V 稳压 |
| 控制箱布局 | 483×377×192 mm，后置后悬 70 mm；实际扫掠约 825 mm；需 1:1 放样 |
| 计算单元未设计 | 只画虚线包络（约 120×165×150 mm），不画内部、不钻安装孔 |
| 末端质量 | 目标 2.6–3.4 kg，硬门槛 ≤3.5 kg；取消主动力控法兰，改 Diana 力控 + 5–10 mm 被动垫 |
| 细/低对比目标 | YOLO 对细、薄、低对比缺陷存在下采样丢边缘、漏检、标注成本高的问题 |
| 通信/控制 | H6Mini 只有 1×RJ45；必须加工业交换机；相机/控制/运维分网；安全硬线优先 |

## 方案与决策

### 1. 整机选型

- 底盘：**H6Mini**（100 kg 自重 / 150 kg 载重，550×530×375 mm）；
- 机械臂：**思灵 Diana 7**（7 轴、7 kg、923 mm、±0.05 mm、28 kg、DC45–65V）；
- 配重：30 kg 低位、居中；
- 控制箱：A 方案后置悬挑 70 mm，扫掠约 825 mm；
- 末端：法兰 → 被动柔顺垫（5–10 mm / 2–3 N）→ 10 mm 转接板 → 电动振动刀（48V、200–400 Hz、静止外壳）→ 钩包刀；2MP 相机侧装 30–45°，WD 150–250 mm，无补光；
- 当前状态：选型方向“有条件通过”，不代表整机定型。

### 2. 供电

```
H6Mini 48V
 ├─ 25A 可控 → 断路器 → 主接触器 → 预充 → Diana 控制箱
 └─ 10A 不控 → 熔断 → 48V 母线
      ├─ 安全继电器 → 电动刀头（300W）
      └─ DC-DC 48→24V → 计算单元/相机/交换机
```

关键结论：

- 25A 供臂、10A 供末端；10A 支路计算单元 ≤60W；
- 供电结论改为 **“有条件匹配”**，不是“直接匹配”；
- 必须确认 Diana DC 版本、峰值电流/持续时间、H6Mini 低压截止、连接器、预充/反灌/隔离；
- 急停断 25A 主接触器 + Diana STO + 刀头接触器，IPC 保持供电记录日志。

### 3. 计算单元

- 首选 **Jetson Orin NX 16GB 工业无风扇**：NexAIoT Coeus-3821T；
- 备选 ASRock iEP-6020E-000、iBASE EC3020-NX16；
- 条件备选低功耗 x86（相机只支持 x86 SDK 时）；
- 不选 AGX Orin NRU-220S（2.6 kg、15–75W，性能/质量过剩）、x86+独显（超 10A 预算）；
- 硬条件：2×GbE、24V、≤60W、≤2kg、Ubuntu 22.04/JetPack 6.2；
- **先冻结相机 ARM64/GenICam 支持，再冻结计算单元**；
- 未冻结前只画虚线包络，不钻 4×M4 孔。

### 4. 软件与控制

- Ubuntu 22.04 + ROS 2 Humble；`mission_manager` 唯一主控；
- 节点：`chassis_bridge`、`arm_bridge`、`vision_node`、`safety_monitor`、`calibration_node`、`logger`；
- 状态机：

```
IDLE → PATROL → DOCK → SETTLE → ARM_HOME → ARM_APPROACH
 → DETECT → DECIDE
   ├─ no → RETRACT → RESUME
   ├─ uncertain → DETECT 重拍 → 仍不确定 → FAULT
   ├─ has → CUT → RETRACT → RESUME
   └─ invalid → FAULT
```

- 检测非接触（WD 150–250 mm）；切割贴辊 3–5 N，最大 30 N，进给 50–150 mm/s；
- 视觉四态：有/无/不确定/无效；置信度高 0.8、低 0.5；
- 主控只发高层指令；Diana 1 kHz 力控在控制箱内部，不下放 IPC；
- 坐标链：

```text
map → odom → base_link → arm_base → tool0 → camera
station_<id> → roller_<id>

arm_base_T_station
  = inverse(base_link_T_arm_base)
  × inverse(map_T_base_link)
  × map_T_station
```

- 检测位/切割位分开示教；相机优先装在被动垫上游，保证外参一致。

### 5. 通信

- H6Mini 只提供 1×RJ45；必须加工业交换机；
- IPC 至少 2×GbE：NIC1 直接接相机，NIC2 接控制交换机；
- VLAN：控制 10 / 相机 20 / 运维 30；全部静态 IP；
- 相机 VLAN 开 Jumbo 9000；控制 VLAN 关 EEE；
- PTP 优先；否则 NTP + 触发时间戳补偿；时间同步丢失 → 视觉 `invalid`，不切割；
- ROS 2 DDS：绑定网卡、unicast peer、控制 reliable / 图像 best_effort、状态 keep_last 10；
- 心跳 100 ms；丢失 500 ms → 臂停、底盘停、刀头断电、`FAULT`；
- **断网即安全态，不自动恢复**；WiFi/4G 只做运维，不跑控制/图像。

### 6. 安全

- 急停、STO、刀头继电器、Work/Transit 许可全部硬线；
- WorkPermit：底盘停稳/抱闸 → 允许臂；
- TransitPermit：臂 home/刀头断电 → 允许底盘；
- 急停后保持停止、人工复位；只有可恢复异常才允许受控撤回；
- 目标 PL d、急停 <100 ms；软件不是安全认证件；
- 切割前滚筒停转必须外部确认，不能只靠软件假设。

### 7. YOLO 工业成熟度

- YOLO 模型/工具链成熟：YOLO26 edge-first，TensorRT/ONNX，Ultralytics Enterprise License；
- 但**没有针对“滚筒下侧无补光细毛线”的现成交钥匙方案**；
- 你的场景是细/薄/低对比小目标，通用 YOLO 可能漏检；建议同台对比：
  - YOLO26-seg / YOLO11-seg；
  - EfficientAD / PatchCore（Anomalib）；
  - 传统 CV 基线；
- 推荐混合管线：ROI/几何校正 → 异常检测判“有无” → 分割/边缘出轴向 → 四态输出；
- 先验证无补光成像；如果图像里不可分割，先改光学/补光，不要继续调模型；
- Ultralytics 默认 AGPL-3.0，闭源商业部署通常需 Enterprise License。

## 补充：H6 Mini × Diana 7 集成可行性复核（2026-11-01）

针对“H6 Mini 能否装 Diana 7”重新抓取两家原始资料，并形成独立备忘录。核心结论不变（机械可行、供电“有条件匹配”），但官方数据表补齐了关键证据，也暴露出项目文档中的三处口径差异。

### 官方一手参数与差异

| 项目 | 官方值（2026-10-31 抓取） | 项目文档现有口径 | 处理建议 |
|---|---|---|---|
| H6 Mini 高度 | 335.5 mm | 375 mm | 核对是否含罩壳/脚轮，按 1:1 放样确认 |
| H6 Mini 对外供电 | DC48V/30A | 25A 可控 + 10A 不控 | 若 30A 为总输出，25+10 同时满载会超限；需书面确认分路与峰值 |

| 控制箱供电 | 110–240 VAC 或 45–65 VDC | AC/DC 待确认 | 官方已明确支持 DC；仍需按 SKU 与铭牌确认 |

### 新增结论

- **稳定性粗算**：臂 26 kg（质心约 0.35 m）+ 末端全伸 0.923 m，倾覆力矩约 150 N·m；100 kg 自重、半轮距 0.26 m 的恢复力矩约 255 N·m，静态安全系数约 1.7。急停/横移动态余量收窄，建议限速、配平并实测。
- **安装可行性**：φ190 底座仅占台面约 10%，臂 + 末端约 30 kg，远低于 150 kg 额定负载；机械上无硬障碍，卡点是顶部孔位图与转接法兰刚度。
- **供电证据**：官方数据表支持 DC 45–65 V，与 H6 Mini 48 V 母线匹配，为直供方案提供书面依据；但“SKU 版本、峰值电流、低压截止、30 A 口径”四项仍未闭环，维持“有条件匹配”。
- **控制箱布置**：17 kg、483×439×160 mm 占台面约 73%，顶置不可取；后置/侧挂需按新尺寸重新放样，原 825 mm 扫掠需复算。

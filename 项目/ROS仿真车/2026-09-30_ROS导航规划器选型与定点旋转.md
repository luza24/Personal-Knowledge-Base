# ROS 导航规划器选型与定点旋转功能

> 整理日期：2026年9月30日 14:58

## 环境信息
- 操作系统：Windows 11 + WSL2 Docker（Ubuntu 20.04 / ROS Noetic）
- 项目：aic26（`aic26_navigation` 包），Gazebo 仿真
- 底盘：滑移转向底盘（差速），`/odom`（nav_msgs/Odometry）、`/cmd_vel`（geometry_msgs/Twist）
- 导航栈：move_base + AMCL + map_server；全局规划器 `global_planner/GlobalPlanner`；局部规划器 TEB / DWA

## 报错记录 / 问题
1. **规划器归属疑问**：用户不确定当前导航用的是 TEB 还是 DWA。
2. **速度慢**：切到 DWA 后线速度被卡在约 0.2 m/s。
3. **偏航严重**：车在每个拐角路点原地旋转对齐朝向，蛇形抖动。
4. **潜在冲突**：`patrol.py`（纯反馈）与 move_base 都会向 `/cmd_vel` 发速度，同时运行会抢话题。

## 涉及文件
- `launch/nav.launch` —— 局部规划器在 TEB / DWA 之间切换
- `config/teb_local_planner_params.yaml` —— TEB 参数（`global_plan_overwrite_orientation: true` 等）
- `config/dwa_local_planner_params.yaml` —— DWA 参数（本次调优）
- `scripts/move_base_patrol.py` —— **新建**，用 move_base 发 goal 实现巡逻
- `scripts/patrol_green_test.py` —— **新建**，纯反馈巡逻 + 定点旋转 + YOLO 视觉检测

## 修改方案

### 1. 规划器诊断
`nav.launch` 中 `base_local_planner = teb_local_planner/TebLocalPlannerROS`，即**当前是 TEB**；DWA 配置（`dwa_local_planner_params.yaml`）存在但被注释未启用。`patrol.py` 是纯反馈控制（纯跟踪 + 曲率减速），直接发 `/cmd_vel`，与 TEB/move_base 无关。

### 2. move_base 巡逻方案（可选路线）
新建 `move_base_patrol.py`：把巡逻路点依次作为 `move_base` 的 goal 下发（`MoveBaseAction`），由 GlobalPlanner 规划、TEB/DWA 跟踪避障；红绿灯停车用 `cancel_goal()` + 计时恢复实现。goal 朝向设为「指向下一路点」，避免原地转正。

### 3. 切换到 DWA
`nav.launch` 中：
- `base_local_planner` → `dwa_local_planner/DWAPlannerROS`
- 加载 `dwa_local_planner_params.yaml`（替代 teb 参数）

### 4. 修复速度慢 + 偏航（DWA 参数）
| 参数 | 旧值 | 新值 | 作用 |
|------|------|------|------|
| `max_vel_trans` | 0.2 | **0.4** | 解除线速度瓶颈（速度慢根因） |
| `yaw_goal_tolerance` | 0.2 | **3.14** | 忽略朝向、到点即切，不再原地转正（偏航根因） |
| `min_vel_theta` | 0.3 | **0.1** | 降低转向下限，减少蛇形抖动 |
| `min_in_place_vel_theta` | 0.3 | **0.1** | 同上 |
| `xy_goal_tolerance` | 0.35 | **0.15** | 更贴近路点，减小抄近道 |

### 5. 定点旋转动作（patrol_green_test.py）
在纯反馈巡逻基础上新增「经过触发点时逆时针转 90° → 停 3 秒 → 转回原方向」：
- 配置区：`SPIN_POINTS`（多触发点列表）、`SPIN_RADIUS=0.3`、`SPIN_ANGLE=π/2`、`SPIN_W=0.8`、`SPIN_WAIT=3.0`
- 状态机：`rotate_ccw → wait → rotate_back → normal`，期间跳过巡逻与红绿灯逻辑
- 每个触发点独立武装（`spin_armed = [True]*len`），离开触发区后重新武装，避免同圈重复触发
- 角度累计用 `normalize_angle(yaw - last_yaw)` 增量，避免 yaw 在 ±π 边界跳变
- 旋转方向：逆时针 = `+cmd.angular.z`（ROS 俯视右手系）

## 结果与结论
- 规划器确认是 **TEB**（非 DWA），后按需求切到 **DWA**。
- 速度慢 / 偏航问题通过 DWA 参数 `max_vel_trans`、`yaw_goal_tolerance` 等修复（参数改动需重启 move_base 才生效）。
- 定点旋转功能已实现（多触发点）；后续 `patrol_green_test.py` 已扩展接入 YOLO 视觉检测服务 `/yolo/detect`（Trigger），检测点停车后跑一次检测。
- 注意：触发点须在真实路径上，否则永远不会触发（如原 `(-0.9, 1.1)` 不在 LOOP_A 上，已改为路径上的点）。

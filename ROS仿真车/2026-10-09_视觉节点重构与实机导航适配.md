## 本次完成内容

### 1. 视觉节点重构（消除重复 + 省内存）
- 新建 `aic26_perception/scripts/vision_utils.py`，抽取两个视觉节点共用的 12 个函数 + 4 组常量（HSV 判灯色、车牌 OCR、车牌模糊匹配 match_plate、NMS 去重、图像编解码等）
- `yolo_save_node.py` 改为**纯存图节点**：不加载模型、不推理，只订阅 `/yolo/annotated_image` 收到即存 png（原来自己加载模型+推理，和 detector 重复，内存翻倍）
- `yolo_detector.py` 标注图新增**置信度 + 车牌匹配结果**（原来只画标签）
- `yolo_detector.py` 启动时**预热 YOLO 推理 + 预加载 OCR**，消除首个检测点冷启动卡顿

### 2. patrol_spin.py 社区统计功能修复（合并丢失的功能）
- 背景：`patrol_spin.py` 新版（10-07）加了车牌模糊匹配、泊车动作，但**丢了旧版（10-06）的 A/B 社区人数统计**
- 恢复：`COMMUNITY_B_POINTS`、`spin_person`（A社区=旋转点）、`task_person`（B社区=任务点）、`detect_objects(bucket)`、`wait_detections()`
- 修复连锁 bug：
  - SpinAction.trigger 误加了 `self.active_point = tp`（`tp` 不存在 → NameError → 旋转点崩溃）
  - TaskAction.trigger 漏加了 `self.active_point = tp`（导致 B 社区人数恒为 0）

### 3. 红绿灯检测点"绿灯停4秒"根因分析
- 根因：**不是逻辑 bug，是冷启动**。第一个检测点首次调 `/yolo/detect` 时，YOLO 推理（torch 初始化 1~3s）+ RapidOCR 懒加载 onnx 模型（2~4s）都集中在这一次；第二个检测点已预热所以快
- 修复：detector 启动时预热推理 + 预加载 OCR

### 4. 代码推送到远程 feature/nav-slam
- 处理：本地落后远程 2 commit（车牌 OCR 改进），工作区改动与远程重叠
- 流程：备份 → stash → ff pull → pop 冲突 → 用 stash 版本覆盖 4 个冲突文件 → commit → push
- commit `5f890fb`：视觉重构 + save_node 纯存图 + YOLO 预热 + 社区统计 + README
- 排除：测试产物（patrol_eval_*、yolopng）、.vscode 等

### 5. 导出代码到 aic108（实机部署）
- 范围：9 个包（navigation/perception/slam/description + 5 个骨架包），排除仿真专用 aic26_gazebo、gazebo_ros_model_color
- 清理：__pycache__、.bak 备份、tl_state_det.pt（旧 stage2，HSV 已替代）
- 实机路径适配：3 个 launch 的 python 路径 `/root/ylovenv` → `/home/mowen/ylovenv`、save_dir 同理、nav.yaml image 路径、detector 加相机 remap `/camera/image_raw` → `/usb_cam/image_raw`
- 实机导航适配（对照日志 TF/话题）：nav.launch `use_sim_time` true→false、删写死 initial_pose、costmap `sensor_frame: laser`→`laser_link`、`topic: scan`→`/scan`

## 报错记录 / 踩坑

| 报错/现象 | 根因 | 解决 |
|---|---|---|
| `ModuleNotFoundError: No module named 'vision_utils'` | roslaunch 走 devel 包装脚本，sys.path 无 scripts 目录 | 节点文件顶部加 `sys.path.insert(0, os.path.dirname(...))` |
| `/usr/bin/env: 'python3\r': No such file or directory` | Windows 编辑后文件 CRLF，shebang 带 \r | `sed -i 's/\r$//'` 转 LF |
| 旋转点不停车（patrol 崩溃） | SpinAction.trigger 误加 `self.active_point=tp`，tp 未定义 NameError | 删该行 |
| B 社区人数恒 0 | TaskAction.trigger 漏加 `self.active_point=tp`，active_point 恒 None | 补该行 |
| 绿灯停 4 秒 | 首个检测点 YOLO 冷启动 + OCR 懒加载 | detector 启动预热 |
| git push 失败 | 本地落后远程 2 commit，工作区与远程重叠 | stash → ff pull → pop 冲突 → 用 stash 版覆盖 |

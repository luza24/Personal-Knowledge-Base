# US 3,958,473 缠丝清除装置专利翻译与解读

## 背景 / 目标

用户拿到一份美国专利 PDF（`C:\Users\luza\Downloads\US3958473.pdf`），要求翻译并解读。该专利是纺织机械领域「自动清除导丝辊缠丝（yarn lap / winder）」的原始专利，1976 年授权，可自由实施。

## 环境信息

- Windows 11 + Git Bash，Python 3.8（miniconda）
- 可用工具：`pdftotext`（mingw64）、`pypdf 5.9.0`、`PyMuPDF 1.24.11`
- Read 工具直接读该 PDF 返回 `Unsupported document type`，必须走外部提取

## 报错记录

- 现象：Read 读取 PDF 报 `PDF file read ... (721KB)` 后跟 `[Unsupported document type: application/pdf]`，拿不到正文。
- 触发条件：扫描版/旧版 PDF 的文本层，模型侧无法直接解析。

## 修改方案

**提取流程（可复用）**

```bash
pdftotext -layout US3958473.pdf us3958473.txt
python -c "
import fitz
d=fitz.open('US3958473.pdf')
for i in range(4):
    d[i].get_pixmap(dpi=110).save('us_pages/p%d.png'%(i+1))
"
```

- 旧专利的双栏文本层会把左右栏交错串行，仅靠 `pdftotext` 会出现「The preferred solution ... inTghreolalenrglaendcotdhiengandgilsek creogdiisntegrdsitshsk」这类乱码。**必须渲染页面图对照还原**，并对个别残缺句子在译文中标注「原文如此」。
- `pdftoppm` 在本机不存在，改用 PyMuPDF 渲染即可。

**专利要点（解读结论）**

- 基本信息：US 3,958,473，发明人 Erich Lenk，受让人 Barmag Barmer Maschinenfabrik AG；申请 1975-06-18，德国优先权 DE 24 29 055.5（1974-06-18）；11 项权利要求、6 幅图。
- 核心方案：一个由工作辊自身驱动的滑梭（runner）携切刀沿辊轴全幅往复扫掠，一次行程只需辊转几圈，缠丝来不及叠厚。
- 两种驱动：
  1. 硬辊（钢）辊面开螺旋导槽，梭体被正位移驱动；推荐螺旋升角 30°–60°、最好 <45°。
  2. 软涂层辊（橡胶/软木/弹性塑料）不能开槽，用独立反向缠绕辊经齿带耦合；**工作辊 RPM : 滑梭双行程数 = 整数**（「镜像形成」判据），保证刀只走一条重复轨迹，避免在涂层上刻出多条相位错开的沟槽。
- 切割几何：楔形刃口朝运转方向，钝化凸出部**伸入导槽、低于辊面**，先从缠丝下方「抄起」使其张紧，再在锋利刃段切断——不啃辊面，也更容易切断高旦多丝束。
- 气流排屑：刀旁气嘴顺出丝方向吹，断头被运行中的纱线直接带走，省去收集装置。
- 检测/计数/定位：刀头以转轴+弹簧浮动安装，遇缠丝顶开→触点闭合→脉冲；辊轴角度编码盘（霍尔/光电）给角坐标；ROM 分配器把角度按传动比换算成长度坐标；解复用器+与门把脉冲分箱到第 i 段计数器/灯 → 得到每段断头数，即「每 1000 米断头数」质量指标。等于**用切刀本身做传感器**，零额外检测件。
- 权利要求结构：仅 Claim 1 为独立项（滑梭+切刀+驱动+与辊耦合，范围极宽）；Claim 2/3 锁定反向缠绕辊与整数速比；Claim 4/5 锁定辊面开槽；Claim 6 锁定钝头刃形；Claim 7 锁定气嘴；Claim 8–11 锁定检测统计链。
- 法律状态：1976 年授权，按当时 17 年保护期约 1993 年到期，早已进入公有领域；实施前仍建议检索同族与后续专利。
- 时代局限：螺旋槽机械正位移磨损大、速比固定柔性差、触点检测受油污影响、硬件逻辑现可由 MCU 替代；但「随动执行器 + 全幅扫掠 + 钝头挑起 + 顺流吹除 + 位置分箱」的骨架仍是现代卷绕/导辊清洁装置的原型。

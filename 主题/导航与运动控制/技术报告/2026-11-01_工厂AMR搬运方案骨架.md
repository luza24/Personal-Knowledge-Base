# 工厂 AMR 自主搬运方案骨架（窄通道会车与标准化载具）

> 整理日期：2026年11月01日 19:39
> 项目：技术报告 ｜ 状态：进行中 ｜ 标签：`方案选型` `ros` `导航` `amr`

## 背景 / 目标

课程作业（2 天内交）：工厂内数十台机床并排，排间通道净宽约 1.5 m（可容两人并排行走）。要求实现每台机床产物（服装类织布）的搬运，机器人需在全厂自主导航 + 搬运。不考虑资金，只针对功能，产出含硬件选型、软件选型、技术架构、实施路线的完整方案。

**题目歧义**：说「机床」但产物是「服装类织布」——金属切削机床产物为刚性零件，纺织机械（织机/圆机）产物为布卷/片料，抓取方式完全不同。骨架按**柔性物料（布卷类）**撰写，若实为金属件则难点 4 可删除。

## 核心判断

题眼不在导航——导航是整个方案里最成熟、最没区分度的部分。真正的门槛是两处：

1. **1.5 m 通道的多车会车**：车宽 0.7–0.8 m，两车相遇几何上无解。这是**几何问题不是算法问题**。死锁四形态：窄道迎面相遇、交叉口环形等待、共享资源（工位/充电桩）排队溢出、地图设计缺陷（缺避让点 / 未设单向）——第四种最常见也最好消灭。
2. **怎么从机床取货**：柔性布料抓取是系统里唯一没有成熟工业解的部分，不能与成熟的导航技术绑在同一阶段。

## 三个关键决策

| 决策 | 内容 | 理由 |
|---|---|---|
| 一 | 一期不做自动上下料，做「人机协作搬运」 | 把未验证的难题（柔性抓取）与已验证的工程（AMR）解耦；且任务可靠性连乘——10 个环节各 99%，整链只剩约 90%，减少环节本身就是可靠性设计 |
| 二 | 改造工件而非改造机器人（统一周转箱 / 布卷架） | 用标准工装能消灭的难题不要用机器人智能硬解；每消灭一个自由度，可靠性指数级上升 |
| 三 | 通道做单向环路 + 避让点，不考验会车 | 属布局设计，必须开工前定，后期改要动整个厂 |

## 技术要点

- **架构五层**：L4 业务（MES 对接）/ L3 调度 RCS（任务分配·交通管制·死锁检测恢复）/ L2 导航（SLAM + Nav2 + 二次精定位）/ L1 控制（底盘·举升·安全回路）/ L0 硬件。
- **一期车型**：潜伏顶升式 AMR，载重 100–300 kg，**车宽 ≤0.8 m**（1.5 m 通道的硬上限，两侧各留 0.35 m）。
- **两段式对接**：远距离 SLAM 导航（±2–5 cm）→ 二维码/反光板精定位（需 ≤±10 mm；上机械臂需 ≤±2 mm）。
- **移动机械臂的坑**：误差叠加 = 停靠误差 + 定位误差 + 底盘晃动 + 臂重复精度 + 工装位置。厂商标称的臂重复精度是在**固定基座**上测的，不能直接套用到移动底盘。
- **软件**：Ubuntu 22.04 + ROS 2 Humble + Nav2 + SLAM Toolbox / Cartographer + AprilTag/二维码 + Open-RMF（或商用 RCS）+ Gazebo/Isaac Sim + Foxglove。
- **Open-RMF 的实话**：简单到中等复杂度的调度与冲突消解有效；复杂阻塞、多车互锁、复杂门梯冲突能力不足；文档不完善。方案里建议写成「开源基座 + 自研增强」或直接商用 RCS，**两条路都写并说明取舍**。
- **安全依据**：ISO 3691-4；人机混行区限速建议 ≤1 m/s；安全型激光扫描仪 + 减速区/停止区 + 急停。
- **实施分期**：P0 仿真验证 → P1 单车单工位 → P2 全厂覆盖 → P3 多车调度 → P4 自动上下料 → P5 系统集成。
- **车队规模**：不要盲目加车，研究显示存在吞吐拐点，超过后阻塞时间单调上升。
- **仿真验证法**：按 1.5 倍峰值流量跑，记录死锁次数/位置/平均等待与恢复时间，迭代到零死锁或可自动恢复。
